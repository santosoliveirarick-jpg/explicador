# cantinho-flask
Servidor Flask de exemplo para aula do Cantinho Digital

## Histórico de consultas

O app salva tema, nível e explicação na tabela `consultas` do Supabase após gerar cada resposta. A rota `/historico` mostra os registros mais recentes.

No SQL Editor do Supabase, crie a tabela e as políticas de acesso para a chave `anon` usada no app:

```sql
create table public.consultas (
	id bigint generated by default as identity primary key,
	tema text not null,
	nivel text not null,
	explicacao text not null,
	created_at timestamptz not null default now()
);

alter table public.consultas enable row level security;

create policy "Permitir leitura de consultas" on public.consultas
	for select to anon using (true);

create policy "Permitir cadastro de consultas" on public.consultas
	for insert to anon with check (true);

grant select, insert on table public.consultas to anon;
grant usage, select on sequence public.consultas_id_seq to anon;
```

Configure `SUPABASE_URL` com a URL do projeto e `SUPABASE_KEY` com a chave pública `anon` como variáveis de ambiente do app. No Vercel, cadastre ambas nas configurações do projeto e faça um novo deploy. Essas políticas abertas servem apenas para este exemplo didático; um app real deve restringir acesso e gravação por usuário.
